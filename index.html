Optimizing Memory Management in Operating Systems: Innovations and Challenges

In the rapidly evolving landscape of computing, efficient memory management stands as a cornerstone challenge, grappling with the escalating complexity posed by burgeoning application demands and data volumes across diverse computing platforms. This paper addresses the escalating complexity of memory management in modern computing environments due to increasing application demands and data volumes. Through the exploration of advanced techniques like Page Attention and dynamic memory management, it aims to enhance memory efficiency and system performance across diverse platforms. Key research focuses include the introduction of PagedAttention for large language model (LLM) serving and Marvin, a runtime-level swapping mechanism for mobile operating systems. Findings reveal significant throughput improvements with PagedAttention and promise for enhanced user experience with Marvin.

Greedy Algorithm

This paper explores the average-case performance of greedy routing algorithms in N×N arrays, offering a detailed theoretical analysis across various conditions. It demonstrates that certain greedy store-and-forward techniques can effectively route packets to their destinations with a delay of O(log N) and a maximum queue size of 4, with high probability. Additionally, the analysis extends to dynamic routing situations, showing that if the overall packet arrival rate remains below the network’s capacity, the expected delay stays consistently low, regardless of N. The findings uncover significant efficiencies in greedy algorithms, challenging earlier beliefs about their performance in worst-case scenarios. This research enhances theoretical knowledge and provides practical insights for optimizing routing in large-scale parallel computing systems.

Secure Code Review and Static Analysis Tools

Secure code review and static analysis tools are critical components in modern software development for ensuring the security and robustness of applications. These tools help developers identify vulnerabilities and coding errors early in the software lifecycle, reducing the risk of security breaches. Secure code review involves manual or automated inspection of source code to detect potential security flaws, while static analysis tools automatically analyze the code without executing it, flagging issues such as buffer overflows, memory leaks, and insecure coding patterns. This paper explores the importance of integrating secure code review and static analysis tools in the development process, their strengths and limitations, and how they complement each other to enhance overall software security.

Machine Learning-Based Intrusion Detection

Intrusion Detection Systems (IDS) are vital for identifying malicious activities within network traffic. Traditional IDS struggle to detect novel or evolving attack types. This study evaluates the effectiveness of multiple machine learning (ML) models, spanning traditional classifiers, neural networks, and unsupervised anomaly detection, for detecting DNS spoofing-based attacks. Using a real-world network traffic dataset, we train Random Forest, Support Vector Machine (SVM), XGBoost, and Multi-Layer Perceptron (MLP) classifiers, and compare them with neural and unsupervised models. Models are evaluated using precision, recall, F1-score, and confusion matrices.

Deepfake Text Detection Systems for Arabic and English Using BERT and ELECTRA-Based Models

The rapid advancement of large language models (LLMs) has made AI-generated text increasingly human-like, raising concerns regarding academic integrity, misinformation, and authorship authenticity. Detecting deepfake text has therefore become an essential challenge, particularly in multilingual contexts where resources remain limited. This study investigates the effectiveness of transformer-based models in distinguishing human-written from AI-generated text, focusing on Arabic and English fine-tuning while preparing resources for future Arabic detection. Two datasets were collected and preprocessed, and three different transformer models were fine-tuned and evaluated for binary AI-text classification. Experimental results demonstrate clear performance differences between models, with DeBERTa-v3-base achieving the highest accuracy for English and AraELECTRA for Arabic.
